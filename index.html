El HTML funciona sin servidor. Para recibir Syslog real inicia el servidor Python incluido y pega el token que aparece en su consola. La conexión utiliza 127.0.0.1.

Funciones habilitadas por el servidor

• Colector UDP/TCP Syslog en localhost:5514
• Persistencia SQLite de eventos y mediciones ópticas
• Auditoría con cadena HMAC verificable
• Agente de análisis de solo lectura con Ollama opcional

El token protege las APIs HTTP locales, pero Syslog UDP/TCP no autentica el emisor. No lo expongas a Internet.
